# Shared system launcher blocklist.
# One basename pattern per line, matched case-insensitively against the
# original .desktop filename (source_desktop). `*` and `?` are globs.
# Lines starting with `#` and blank lines are ignored.
# This only filters `desktop:` apps. Raw binaries still use `excludes`.
# Users can force-show with system_apps.allowlist or --show-system.
